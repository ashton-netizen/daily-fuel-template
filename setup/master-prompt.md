# The setup prompt

Open this folder in the Claude desktop app (the Code tab), then paste everything inside the box below as your
first message. That is the whole setup: Claude does the rest and tells you the few steps only you can do.

```
Set up my own Daily Fuel from this folder.

Read CLAUDE.md first, then follow setup/claude-setup.md one step at a time. Interview me in plain
conversation using setup/interview.md: never answer a question for me and never invent my beliefs,
purpose or goals. Then build my version, publish it as a private page in my Claude account, put my
answers into its own store, and look at the published page to check it before you tell me it is done.
Where a step has to be mine (connecting Gmail and Calendar, the optional morning email), give me one
step at a time and wait. Never share the page by public link.
```

If you do not use the desktop app, you can still read [`SETUP.md`](../SETUP.md) and do the steps by hand, but
the interview-and-build flow above is the intended way.
